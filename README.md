# 영화 추천 시스템 (Movie Recommender)

본 프로젝트는 사용자 고유의 영화 평점 데이터를 기반으로 사용자 간 유사도(취향 동질성)를 계산하고, 가중 평균 알고리즘을 적용하여 개인 맞춤형 영화를 정밀 추천하는 C++ 기반 콘솔 애플리케이션입니다.

##  2. 클래스 구조 및 아키텍처 (Class Structure)
본 시스템은 객체지향 설계 원칙(SOLID) 및 단일 책임 원칙(SRP)을 준수하여 도메인 객체와 비즈니스 로직 매니저를 명확히 분리했습니다.

* **`Movie` / `User` / `Rating`**: 영화, 사용자, 평점 데이터를 캡슐화한 순수 도메인 엔티티 클래스.
* **`MovieManager`**: 영화 데이터 로드/저장 및 통합 평점 통계 관리.
* **`UserManager`**: 유저 추가, 검색 및 예외 방어선 구축.
* **`RatingManager`**: 전체 평점 장부 관리 및 특정 유저의 평점 리스트 필터링.
* **`SimilarityCalculator`**: 두 유저 간의 취향 유사도를 계산하는 유틸리티 클래스.
* **`Recommender`**: 유사도 기반 가중 평균 알고리즘을 적용한 핵심 추천 엔진.

##  3. 빌드 및 실행 방법 (Build & Run Instructions)

### 요구 사항
* **OS**: Linux (Ubuntu / WSL 환경 권장)
* **Compiler**: g++ (C++17 표준 지원 표준 빌드)
* **Tools**: GNU Make, Valgrind (메모리 검증용)

### 명령어 순서
프로젝트 루트 폴더(`movie-recommender`) 터미널에서 다음 명령어를 순서대로 실행합니다.

```bash
# 1. 기존 빌드 파일 정리 및 디버깅 기호 포함 재빌드
make clean
make

# 2. 프로그램 실행
./movie_recommender
```

##  4. 주요 기능 상세 설명 (Core Features)

본 시스템은 사용자 중심의 직관적인 메뉴 인터페이스를 제공하며, 입력 버퍼 오염 방지 및 견고한 데이터 정합성 검증 엔진을 탑재하고 있습니다.

### [영화 관리 모듈]
* **1. 영화 추가 (Add Movie)**: 공백을 포함한 영화 제목 및 장르를 `std::getline`으로 안전하게 입력받으며, 개봉 연도를 정수형 변환(`std::stoi`)하여 새로운 `Movie` 객체 인스턴스를 동적 스퀀스 ID 생성 규칙에 따라 컨테이너에 적재합니다.
* **2. 제목으로 검색 (Search by Title)**: 영화 데이터베이스를 순회하며 제목이 100% 일치하는 영화를 검색합니다. 데이터 부재 시 포인터 크래시 위험이 있는 `nullptr` 반환 대신, 명시적 예외(`std::out_of_range`)를 발생시켜 안전하게 상위 블록으로 제어권을 이관합니다.
* **3. 전체 목록 출력 (Print All)**: 저장된 모든 영화의 ID, 제목, 개봉연도, 장르 및 실시간 집계된 평균 평점을 스트림 연산자 오버로딩(`operator<<`)을 통해 격자 형태로 깔끔하게 콘솔에 출력합니다.
* **4. 평점순 정렬 출력 (Sort by Rating)**: 등록된 영화 객체들을 평균 평점 기준 내림차순(Descending Order)으로 정렬하여 사용자에게 박스오피스 형태의 탑 티어 리스트를 실시간으로 스캔하여 제공합니다.

### [사용자 관리 모듈]
* **5. 사용자 추가 (Add User)**: 새로운 이용자의 이름과 이메일 프로필 정보를 입력받아 내부 고유 인덱스를 매핑하고 유저 풀 벡터에 보관합니다.
* **6. 사용자 목록 출력 (Print Users)**: 현재 서비스에 가입 및 적재된 전체 사용자 명단을 안전한 상수 포인터 순회 방식으로 콘솔에 출력합니다.

### [평점 입력 및 협업 필터링 추천 엔진]
* **7. 평점 입력 (Submit Rating)**: 
  * 유저 이름과 영화 제목을 동시에 조회하여 둘 다 실존할 때만 평점 등록 프로세스를 수행합니다.
  * 입력받은 실수형 평점(`std::stod`)이 유효 범위인지 가드 클로즈(`score < MIN_SCORE || score > MAX_SCORE`)로 검증하여 데이터 오염을 원천 차단합니다.
* **8. 영화별 평점 보기 (View Movie Ratings)**: 특정 영화 고유 ID를 외래키(Foreign Key)로 삼아 `RatingManager` 장부에서 매칭되는 모든 유저들의 개별 평점 투표 이력을 역추적하여 출력합니다.
* **9. 맞춤 영화 추천 받기 (Collaborative Filtering Recommendation)**:
  * 본 시스템의 핵심 추천 아키텍처입니다. 대상 사용자와 타 사용자들 간의 공통 영화 소비 이력을 대조하여 공통 관람 편수 가중치 및 평점 편차를 결합한 커스텀 취향 유사도 공식를 연산합니다.
  * 나와 가장 취향이 닮은 상위 K명의 유사 유저들이 높게 평가했으나, **내가 아직 관람하지 않은 유망 영화 N개**를 수학적 가중 평균 알고리즘으로 계산하여 탑 매칭 영화 객체 주소 리스트를 반환, 정밀 추천을 수행합니다.

## 5. M4 확장 통계 기능 설명 (Extensions)

### [기능 10] 전체 영화의 통합 평균 평점 조회 기능
* **소속 파일 경로**: `include/MovieManager.h` (선언부) / `src/MovieManager.cpp` (구현부)
* **기획 배경 및 기술 핵심**: 
  * 개별 영화 단위의 평점 통계를 넘어, 데이터베이스 전체에 누적된 영화들의 통합 평균 지표를 산출하여 서비스 관리자 통계 리포트를 고도화하기 위해 신설되었습니다.
  * `MovieManager` 컨테이너 내부에 보유한 모든 `Movie` 인스턴스의 개별 평균값들을 런타임에 동적 순회 누적한 후, `movieMgr.size()` 편수로 나누어 산술평균을 도출합니다.
  * **Zero-Division 방어선 구축**: 만약 데이터베이스 초기 로드 실패 등으로 인해 영화 컨테이너가 비어있을 경우 발생할 수 있는 '0으로 나누기(NaN)' 연산 오류를 방지하기 위해 `main.cpp` 진입부와 내부 수식에 `try-catch (std::exception)` 예외 처리 그물망을 이중으로 장착하여 시스템 다운타임을 완벽하게 극복했습니다.
